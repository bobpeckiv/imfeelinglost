# I'm Feeling Lost

Source for imfeelinglost.org, a free self-help library. A small Python script builds a static site.

- Edit text in `src/content.py` and `src/content2.py`.
- Edit look and behavior in `src/style.css` and `src/site.js`.
- Build locally with `python3 src/build.py`. Output goes to `site/`.
- Every push to `main` rebuilds and deploys through GitHub Actions.
